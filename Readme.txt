DevSecOps AI – AI-Powered Security Scanning & Vulnerability Remediation Platform

Designed, developed, and deployed an AI-powered DevSecOps platform that centralizes security scanning, vulnerability detection, and AI-assisted remediation across development and deployment workflows.

Key Features:

Dockerfile security scanning with AI-powered vulnerability analysis and fixes.
Docker image vulnerability scanning.
Jenkinsfile security scanning and secure pipeline configuration.
AI-powered generation of Dockerfiles, Jenkinsfiles, and Kubernetes YAML manifests.
Kubernetes configuration and security scanning.
Git repository security scanning.
Dependency vulnerability scanning.
Centralized dashboard to monitor recent scans, findings, and scan history.
PostgreSQL database integration for storing scan records.
Secure Google authentication for user access.
AI-powered analysis and remediation running on a separate server.
Infrastructure & Deployment:

Deployed on Google Cloud Platform (GCP) QA environment.
Docker-based deployment with dedicated Dockerfile, Kubernetes, and Jenkins configuration directories.
Configured GCP Internal Load Balancer for application access.
Secured application access through corporate VPN connectivity.
Integrated PostgreSQL for persistent data storage.
Focus Areas: DevSecOps, AI-Assisted Security, Docker, Kubernetes, Jenkins, CI/CD, GCP, PostgreSQL, Git Security, Vulnerability Management.
